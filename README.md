# 실리 책방 · Silly Bookshop

**0.3.2-test.1 · 공개 배포 전 테스트 버전**

실리의 채팅을 읽는 개인용 웹 화면과 안드로이드 앱입니다. 각 사용자는 **자기 실리 서버**에 이 서버 플러그인을 설치하고, 앱에 자기 서버 주소를 입력합니다. 중앙 채팅 서버나 제작자 계정은 필요하지 않습니다.

실리 캐릭터 프사, 캐릭터 바로 아래로 펼쳐지는 대화 목록, 말풍선, 실리에서 처리된 최종 번역·HTML/div/CSS 화면, 밝은/어두운 화면, 글자 크기와 기기 사이 읽던 위치 복원을 지원합니다.

## 설치 구조

이 저장소를 통째로 `SillyTavern/plugins/sili-library`에 clone하면 최상위 `package.json`의 `main: server/index.cjs`로 로드됩니다. **일반 확장 설치 메뉴에 넣지 않습니다.** 실행용 외부 npm 의존성이 없어 `npm install`도 필요 없습니다.

Android 8 이상 / Node.js 18 이상. 실리가 실행 중이어야 읽을 수 있습니다. 실리 계정을 쓰는 경우 각 계정의 채팅만 읽습니다.

## 터먹스에 최초 설치

먼저 실리 서버를 `Ctrl+C`로 중지합니다. 기존 실리 경로가 `~/SillyTavern`인 경우:

```sh
cd ~/SillyTavern
read -r -p "책방 깃허브 저장소 주소를 붙여넣으세요: " SILI_REPO_URL
git clone -- "$SILI_REPO_URL" plugins/sili-library
cd plugins/sili-library
node scripts/enable-plugin.cjs
node scripts/install-bridge.cjs
node setup.cjs
```

아직 저장소를 만들지 않았다면 위 clone 단계는 기다려 주세요. 먼저 이 공개용 ZIP을 압축 해제해서 **그 안의 파일/폴더를 저장소 최상위에 업로드**합니다. 최상위에 `package.json`, `setup.cjs`, `server`, `android`가 보여야 합니다. ZIP 파일 자체를 올리는 것으로는 clone 설치가 되지 않습니다. 숨김 파일 `.gitignore`, `.gitattributes`도 포함하세요.

`enable-plugin.cjs`는 config.yaml을 백업하고 `enableServerPlugins`만 true로 바꿉니다. 기존의 다른 서버 플러그인도 함께 활성화될 수 있습니다. 이미 true이면 파일을 바꾸지 않습니다.

비밀번호는 **12자 이상**으로 두 번 입력합니다. 글자나 별표가 화면에 안 나오는 게 정상입니다. 기본 계정이 아니라면 사용자 데이터 폴더를 직접 지정하세요:

```sh
node setup.cjs "$HOME/SillyTavern/data/사용자핸들"
```

사용자 지정 실리 경로라면 `enable-plugin.cjs` 뒤에 config.yaml 전체 경로를 넣을 수 있습니다. 비밀번호를 잊었을 때도 setup.cjs로 재설정하며 이전 로그인은 무효화됩니다.

실리 다시 시작:

```sh
cd ~/SillyTavern
bash start.sh
```

콘솔에 `[실리 책방 0.3.2-test.1] /api/plugins/sili-library/`가 표시됩니다.

## 번역·정규식·HTML 최종 화면 연동

**0.3.1부터 실리에서 실제로 표시된 최종 화면만 보여 줍니다.** 파일 원문·저장 번역문으로 대체하거나, 원문 펼치기/모두 보기로 숨긴 띵킹을 다시 꺼내지 않습니다. 채팅 API에서도 원문·번역 필드를 보내지 않습니다.

1. `node scripts/install-bridge.cjs` 실행 후 실리 브라우저를 새로고침합니다.
2. 확장 설정에 **실리 책방 · 화면 연동 (0.3.1)**이 보이는지 확인합니다.
3. 실리에서 읽을 대화를 엽니다. 로드된 메시지가 약 5초 간격으로 순차 연동됩니다. 오래된 메시지는 실리에서 스크롤해 로드하면 됩니다. ‘지금 다시 연동’으로 재전송할 수도 있습니다.
4. 책방에서 같은 대화를 열거나 위쪽 ‘새로고침’을 누릅니다.

- 번역과 정규식이 적용된 `.mes_text`의 실제 DOM과 스타일을 저장합니다. HTML/div/CSS/표/details 등을 정적 화면으로 표시합니다.
- CSS/hidden/aria-hidden 등으로 숨긴 요소와 HTML 주석·data 속성은 복사본에서 제거합니다. 정규식으로 없어진 부분은 복사하지 않습니다.
- 아직 연동되지 않은 메시지는 **실리 화면 연동 대기**라고 표시합니다. 이는 서버 로딩 오류와 다릅니다. 원문은 대신 보여 주지 않습니다.
- 0.3.0 복사본은 숨김 처리 전 자료일 수 있어 표시하지 않습니다. 업데이트 후 실리에서 대화를 다시 열어 새 방식으로 연동해야 합니다.
- 원문·번역·스와이프가 바뀌면 이전 화면을 제외하고 새 연동을 기다립니다. 실리에서 정규식 설정을 바꿨다면 그 대화를 다시 표시하고 ‘지금 다시 연동’을 눌러 주세요. 실리가 닫힌 상태의 정규식 설정 변경을 책방이 즉시 알 수는 없습니다.
- 실리에서 안 보이는 별도 번역 필드를 추가로 끼워 넣지 않습니다. 번역문을 함께 보고 싶다면 실리 화면에 함께 표시된 상태로 연동합니다.
- 보조 확장은 생성·번역 API, 원본 채팅, 프리셋, `settings.json`을 수정하거나 가로채지 않습니다. 자신의 서버 전용 폴더에 화면 복사본만 저장합니다.

JavaScript 버튼 동작, 외부 iframe, 외부 이미지·폰트·CSS URL을 실행하지 않습니다. 같은 서버의 접근 가능한 이미지/프레임은 정적 결과를 옮길 수 있지만 외부 또는 접근 불가능한 프레임, 캔버스, 의사 요소, 웹폰트는 다를 수 있습니다. 모든 확장의 런타임을 그대로 실행하는 제품은 아닙니다.

## 로그인 순서

실리에 사용자 계정 로그인/기본 인증을 설정했다면 먼저 그 인증을 통과합니다. 이미 로그인된 세션이라면 화면이 생략될 수 있습니다. 실리 자체 인증을 쓰지 않으면 책방 비밀번호만 입력합니다. IP 허용 목록·테일스케일 제한 등 기존 실리 접속 규칙은 그대로 적용합니다.

## 불러오기에 실패할 때

- 무응답은 최대 20초 뒤 오류와 ‘다시 불러오기’ 버튼으로 바뀝니다. 계속 로딩 문구만 유지하지 않습니다.
- 사진은 화면에 가까운 것부터 동시에 2개까지만 읽으며 일시적 429 오류를 재시도합니다. 사진 실패를 영구 캐시하지 않습니다. 위쪽 ‘새로고침’으로 다시 요청할 수 있습니다.
- HTML 표시 파일이 누락됐거나 서버 버전이 맞지 않으면 안내합니다. 책장 아래에 서버/화면 버전이 표시됩니다.
- 현재 계정의 PNG 캐릭터 카드가 있는 캐릭터만 표시합니다. 사진을 읽지 못하면 이름 첫 글자로 대신 표시하며 새로고침으로 재요청합니다.

## APK 연결

공개용 소스 ZIP에 APK나 서명 키를 섞지 않습니다. 테스트 APK 또는 이후 GitHub Releases의 APK를 폰에서 열어 설치하세요.

- 실리 터먹스가 있는 **같은 폰**: `http://127.0.0.1:8000`
- 다른 안드로이드 기기: 테일스케일을 켜고 `http://100.x.y.z:8000` 또는 해당 `.ts.net` 주소
- 별도 HTTPS 서버: 본인이 관리하는 `https://서버주소`

포트가 다르면 8000을 실제 포트로 바꿉니다. 실리 기본 주소만 넣으면 책방 경로는 자동으로 붙습니다. 하위 경로 프록시는 지원하지 않습니다.

실리 자체 인증이 있으면 먼저 실리 로그인 후 위쪽 **책방**을 누르고, 책방 비밀번호를 입력합니다. 기존 `0.1.x` 앱은 삭제 없이 새 APK로 업데이트 가능합니다. 기존 HTTP LAN 주소(192.168.x.x 등)는 이 버전에서 차단하므로 localhost/테일스케일/HTTPS 주소로 바꿔 주세요.

0.3.1부터 앱의 스크린샷 차단 설정을 제거했습니다. 일반 캡처가 가능하며 최근 앱 화면에도 내용이 보일 수 있습니다. 서버 주소를 변경하면 앱 안의 이전 쿠키와 웹 저장 데이터를 비웁니다.

## 컴퓨터에서 읽기

테일스케일로 실리를 여는 주소 뒤에 `/api/plugins/sili-library/`를 붙입니다. 예:

```text
http://100.x.y.z:8000/api/plugins/sili-library/
```

403이면 같은 서버의 실리 메인 화면에서 먼저 로그인하고 돌아오세요. 네트워크 제한 안내가 나오면 localhost/테일스케일/HTTPS를 확인합니다. 실리의 기존 IP 허용 목록과 로그인 제한은 그대로 적용됩니다.

## 캐릭터 목록과 새로고침

- 현재 실리에 남아 있는 캐릭터 카드 기준으로 목록을 만듭니다. 삭제된 캐릭터의 채팅 폴더가 남아 있어도 표시하지 않습니다. 저장된 채팅이 없는 현재 캐릭터도 표시합니다.
- 그룹은 현재 그룹 설정에 등록된 대화만 표시합니다. 삭제된 그룹의 남은 파일은 표시하지 않습니다.
- 책방의 **새로고침**은 캐릭터·채팅 추가/삭제와 프사를 다시 읽고, 열어 둔 대화도 다시 불러옵니다. 현재 캐릭터나 대화가 삭제되었다면 본문과 선택을 비웁니다.
- 실리에 저장된 파일 기준이며, 실리 화면의 검색·정렬·즐겨찾기 설정까지 복제하지는 않습니다. 삭제된 원본 파일을 책방이 직접 정리하거나 삭제하지 않습니다.
- 목록은 화면이 보이는 동안 약 30초마다 자동 확인합니다. 수동 새로고침은 이 주기를 기다리지 않습니다. 최종 메시지 화면은 위의 화면 연동 절차를 따릅니다.

## 동작과 저장 위치

- 활성 대화는 약 5초, 목록은 약 30초 간격으로 서버 파일을 확인합니다. 화면이 숨겨져 있으면 폴링을 멈춥니다.
- 생성 중 아직 실리가 파일에 저장하지 않은 내용은 표시되지 않습니다.
- 읽던 위치는 스크롤을 멈춘 뒤 약 0.65초 후 저장됩니다. 같은 대화를 다른 기기에서 열면 이어 읽습니다. 동시에 읽으면 마지막 저장이 적용됩니다.
- 글자 크기·테마·목록 접힘·최근 선택 ID는 기기 웹 저장소에 보관합니다. 대화 본문을 오프라인 보관하지 않습니다.
- 서버 추가 파일은 해당 계정의 `data/<handle>/.sili-library/auth.json`, `reading.json`, `rendered/`의 화면 복사본입니다. 비밀번호는 salt+scrypt 해시로 저장합니다.
- 원본 JSONL과 `settings.json`, 프롬프트, API 키, 다른 확장 파일은 변경하지 않습니다.
- 추가 AI 호출, 분석/광고 SDK, 제작자 알림, 외부 이미지 자동 요청이 없습니다.

## 업데이트

**기존 0.1.x ZIP 설치자는** 서버를 멈추고 기존 플러그인 폴더를 `plugins` 밖에 백업한 뒤 저장소를 같은 이름으로 clone하세요. 계정 데이터 폴더는 이동하거나 삭제하지 않습니다.

```sh
cd ~/SillyTavern
mv plugins/sili-library "$HOME/silly-bookshop-plugin-backup-$(date +%Y%m%d-%H%M%S)"
read -r -p "책방 깃허브 저장소 주소: " SILI_REPO_URL
git clone -- "$SILI_REPO_URL" plugins/sili-library
```

clone이 실패하면 백업 폴더를 원래 위치로 되돌리면 됩니다. 비밀번호와 읽던 위치는 별도 계정 폴더에 남아 있습니다. 기존 비밀번호가 짧다면 `node setup.cjs`로 새로 설정하세요.

**0.3.1에서 0.3.2로 업데이트할 때 APK 재설치는 필요 없습니다.** Android 앱과 화면 연동 보조 확장은 0.3.1을 그대로 사용하고 서버·책방 화면만 0.3.2로 바뀝니다.

**이미 Git으로 설치한 뒤의 업데이트**는 실리를 중지한 상태에서 실행합니다:

```sh
cd ~/SillyTavern/plugins/sili-library
git pull --ff-only
node scripts/install-bridge.cjs
```

실리 서버를 다시 켜고, 실리 브라우저와 책방 화면을 새로고침합니다. 0.2.x/0.3.0에서 올라오는 경우 새 APK도 삭제 없이 덮어 설치하세요. 책방 비밀번호와 읽던 위치는 유지됩니다.

테스트 버전을 고정하려면 검증한 태그/커밋을 checkout하세요. 실리의 `enableServerPluginsAutoUpdate`가 true이면 시작할 때 Git 플러그인을 자동 업데이트할 수 있습니다. false로 바꾸면 **다른 서버 플러그인의 자동 업데이트에도 영향**을 주므로 본인 운영 방식에 맞게 직접 결정하세요.

## 현재 제한

HTML과 CSS의 정적 표시는 지원하지만 스크립트·외부 리소스·외부 링크 이동은 차단합니다. 대화당 32MiB, JSONL 한 줄 약 1MiB 문자 수, 10만 메시지, 목록 2만 대화 제한이 있습니다. 한 번에 최대 30개 메시지와 약 2MiB의 메시지 데이터를 반환하며 큰 페이지는 더 작게 나눕니다. 첫 메시지는 크기에 따라 이 응답 목표를 넘을 수 있습니다. 읽던 위치의 메시지가 중간 삭제되면 위치가 달라질 수 있습니다.

화면 복사본은 메시지당 512KiB, 대화당 32MiB, 계정 전체 128MiB로 제한하며 한도를 넘으면 연동 설정에 오류를 표시합니다. 한도를 넘은 화면은 연동 대기로 남으며 원문으로 대체하지 않습니다. HTML 프레임 높이는 최대 200,000px입니다.

30분 동안 사용하지 않거나 로그인 후 24시간이 지나면 재로그인이 필요합니다. 실리 서버를 다시 켜도 재로그인이 필요합니다. 앱 종료/네트워크 단절 직전의 위치는 저장되지 않을 수 있습니다. 오프라인 읽기는 아직 없습니다.

실제 폰·터먹스 실기 테스트는 아직 완료하지 않았습니다. 공개하기 전에 [TESTING.md](TESTING.md)를 확인하세요. 보안 범위는 [SECURITY.md](SECURITY.md), 공개 절차와 앱 빌드는 [PUBLISHING.md](PUBLISHING.md)에 있습니다.

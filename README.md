# 실리 책방 · Silly Bookshop

**1.0.0 · Android 앱 / PC 브라우저 / iPhone·iPad 웹앱**

실리에 저장된 채팅을 말풍선과 책장으로 편하게 읽는 개인용 뷰어입니다. 사용자가 **자기 실리 서버**에 서버 플러그인을 설치하고 연결합니다. 중앙 채팅 서버나 제작자 계정은 필요하지 않습니다.

- [Android APK 다운로드 · GitHub Releases](https://github.com/foreverharibo-boop/Silly-Bookshop/releases)
- [변경 기록](CHANGELOG.md) · [보안 범위](SECURITY.md) · [검증 기록](TESTING.md) · [배포·빌드 안내](PUBLISHING.md)

## 주요 기능

- **책장**: 목록형·카드형·책표지형, 즐겨찾기, 정렬, 캐릭터 아래 펼쳐지는 대화 목록. PC·태블릿은 화면 너비와 회전에 따라 열 수가 바뀝니다.
- **이어 읽기**: 처음 여는 대화는 첫 메시지부터, 다시 여는 대화는 마지막 읽던 위치부터. 온라인 위치는 같은 실리 계정의 기기 사이에 공유됩니다. 최근 대화 영역은 접기와 표시 개수 설정을 지원합니다.
- **책방 개인화**: 전용 사진·표지와 대화 별명. 전용 사진은 모든 책장 보기와 대화 속 캐릭터 프사에 적용되며 새로고침해도 유지됩니다. 실리 원본 사진·이름·채팅은 수정하지 않습니다.
- **읽기 도구**: 책갈피와 메모, 현재 대화 내용 찾기, 집중 읽기, 처음/최신 메시지로 이동, 대화 속 프사 표시 선택.
- **디자인**: 화이트·크림·로즈·세이지·밤서재·잉크 테마, 글자 크기·굵게·줄 간격·여백 조절, 테마를 따르는 팝업.
- **글꼴**: 기기 기본, 프리텐다드, IBM Plex Sans KR, 나눔고딕, 고운돋움, 리디바탕, 나눔명조, 고운바탕, 함렛. 폰트를 자체 포함해 외부 폰트 사이트에 연결하지 않습니다.
- **채팅 표시**: 저장된 번역, 지원되는 표시 정규식, Markdown 및 정적 HTML/div/CSS. 실리에서 해당 채팅방을 따로 열어 연동할 필요가 없습니다.
- **오프라인**: 선택한 대화를 기기에 암호화 보관. 서버가 꺼져도 저장한 사본을 읽습니다. 웹 보관함은 HTTPS가 필요합니다.

## 지원 환경과 연결 조건

| 환경 | 온라인 읽기 | 오프라인 보관 |
| --- | --- | --- |
| Android 8 이상 APK | 같은 폰 localhost / Tailscale / HTTPS | 폰 화면 잠금 설정 필요 |
| PC 브라우저 | Tailscale / HTTPS / 같은 PC localhost | HTTPS 또는 같은 PC localhost 필요 |
| iPhone·iPad Safari / 홈 화면 웹앱 | Tailscale / HTTPS | **유효한 HTTPS 연결 필요** |

서버에는 Node.js 18 이상과 실리가 필요합니다. 온라인 열람·갱신에는 실리 서버가 실행 중이어야 합니다. 실리의 기존 로그인·IP 허용 목록은 그대로 적용됩니다. 이 플러그인은 Tailscale, HTTPS 인증서 또는 외부 공개 주소를 자동으로 설정하지 않습니다.

`http://100.x.x.x:포트`는 Tailscale 연결이라도 브라우저의 HTTPS 조건을 충족하지 않습니다. 홈 화면 추가와 온라인 읽기는 가능하지만 **웹 오프라인 보관은 사용할 수 없습니다**. 주소 앞을 `https`로 바꾸기만 해서는 안 되고 서버/신뢰하는 프록시의 HTTPS 구성이 먼저 필요합니다. localhost 예외는 브라우저와 서버가 같은 기기에 있을 때만 적용됩니다.

## 서버 플러그인 최초 설치 — Termux

실리 서버를 `Ctrl+C`로 중지합니다. 실리 설치 위치가 `~/SillyTavern`인 경우 아래를 실행합니다.

```sh
cd ~/SillyTavern &&
git clone https://github.com/foreverharibo-boop/Silly-Bookshop.git plugins/silly-bookshop &&
cd plugins/silly-bookshop &&
node scripts/enable-plugin.cjs &&
node setup.cjs
```

- **일반 확장 설치 메뉴가 아닌 `plugins/silly-bookshop`에 설치**합니다. 추가 브라우저 확장과 `npm install`은 필요 없습니다.
- `enable-plugin.cjs`는 `config.yaml`을 백업하고 `enableServerPlugins`를 켭니다. 이미 켜져 있으면 변경하지 않습니다. 다른 서버 플러그인도 함께 활성화될 수 있습니다.
- 책방 비밀번호는 12~256자로 두 번 입력합니다. 입력 중 글자·별표가 안 보이는 것이 정상입니다. 표시되는 **복구 코드**를 개인적으로 보관하세요.
- 기본 `default-user` 계정이 아니라면 `node setup.cjs "$HOME/SillyTavern/data/사용자핸들"`처럼 해당 사용자 폴더를 지정합니다. 실리의 사용자 지정 데이터 경로를 쓰는 경우도 실제 경로를 지정하세요.
- 사용자 지정 실리 경로에서는 `enable-plugin.cjs` 뒤에 실제 `config.yaml` 경로를 지정할 수 있습니다.

설정 후 실리를 다시 시작합니다.

```sh
cd ~/SillyTavern &&
bash start.sh
```

콘솔에 `[실리 책방 1.0.0] /api/plugins/silly-bookshop/`가 표시됩니다.

### Windows 서버에 설치

실리를 종료하고 **실리 설치 폴더에서 PowerShell**을 연 뒤 순서대로 실행합니다. Git과 Node.js가 설치되어 있어야 합니다. 앞 단계에 오류가 나면 다음 단계로 넘어가지 않습니다.

```powershell
git clone https://github.com/foreverharibo-boop/Silly-Bookshop.git plugins/silly-bookshop
cd plugins/silly-bookshop
node scripts/enable-plugin.cjs
node setup.cjs
```

계정·경로·비밀번호 조건은 Termux와 같습니다. 완료 후 평소 사용하던 실리 실행 방법으로 다시 시작합니다.

## Android 앱 설치와 접속

1. [Releases](https://github.com/foreverharibo-boop/Silly-Bookshop/releases)에서 **`silly-bookshop-1.0.0.apk`**를 받아 설치합니다. Android가 요청하면 다운로드한 브라우저/파일 앱의 설치 권한을 허용합니다.
2. 앱의 **서버 주소**에 실리 기본 주소를 입력합니다. `/api/plugins/silly-bookshop/` 경로는 자동으로 붙습니다.
3. 실리 자체 로그인/기본 인증을 설정했다면 먼저 로그인합니다. 이어 **홈화면**에서 책방 비밀번호를 입력합니다.

| 서버 위치 | 앱에 넣을 주소 예시 |
| --- | --- |
| 실리가 실행 중인 같은 Android 폰 | `http://127.0.0.1:8000` |
| 다른 기기의 Tailscale 서버 | `http://100.x.y.z:8000` |
| 직접 설정한 HTTPS 서버 | `https://본인서버주소` |

`100.x.y.z`는 실제 서버의 Tailscale IP로, `8000`은 실제 실리 포트로 바꾸세요. HTTP 일반 LAN 주소(예: 192.168.x.x)는 앱에서 차단합니다. 서버 하위 경로 프록시는 지원하지 않습니다.

## PC / iPhone / iPad에서 접속

실리 기본 주소 뒤에 `/api/plugins/silly-bookshop/`를 붙입니다.

```text
http://서버의TailscaleIP:실리포트/api/plugins/silly-bookshop/
```

Tailscale은 서버와 접속 기기 모두 연결되어 있어야 합니다. 실리 로그인 화면이 나오면 먼저 로그인하고 같은 책방 주소로 돌아옵니다.

**iPhone·iPad 홈 화면 웹앱:** Safari로 책방 접속 → 공유 → 홈 화면에 추가 → ‘웹 앱으로 열기’가 있으면 켜기 → 추가. 이후 홈 화면의 **실리 책방 아이콘**으로 실행합니다. HTTP에서도 홈 화면 추가는 가능하지만 오프라인 보관까지 쓰려면 HTTPS가 필요합니다.

PC와 태블릿 웹 헤더에는 **홈화면 · 도구 · 잠그기**가 있습니다. PC·일반 iPad 브라우저의 대화 화면에서 삼선으로 옆 목록을 접고 펼칩니다. Android 앱과 iPhone·iPad 홈 화면 웹앱은 삼선을 숨기고 홈/대화를 한 화면씩 보여줍니다.

## 업데이트

이미 `plugins/silly-bookshop`에 설치했다면 실리를 종료한 뒤 실행합니다.

```sh
cd ~/SillyTavern/plugins/silly-bookshop &&
git pull --ff-only &&
cd ~/SillyTavern &&
bash start.sh
```

Android는 **1.0.0 APK를 기존 앱 위에 덮어 설치**합니다. 기존 `app.silly.bookshop` 앱과 같은 서명이며 앱 삭제나 비밀번호 초기화는 필요 없습니다. 브라우저/웹앱은 서버 업데이트 후 새로고침합니다. 버전은 **도구 → 버전과 연결**에서 확인합니다.

`git pull`에서 로컬 변경 오류가 나면 업데이트가 완료된 것이 아닙니다. 변경 파일을 백업하고 확인한 뒤 갱신하세요. 무조건적인 `git reset --hard`나 앱 삭제로 해결하지 마세요.

### 초기 Sili 이름 설치에서 이전하는 경우만

아직 폴더가 `plugins/sili-library`라면 실리를 종료한 뒤:

```sh
cd ~/SillyTavern/plugins/sili-library &&
git pull --ff-only &&
node scripts/migrate-silly.cjs &&
cd ~/SillyTavern &&
bash start.sh
```

본인 책방 폴더와 책방 데이터만 새 이름으로 옮기고 기존 화면 연동 확장을 백업합니다. 이전·새 데이터 폴더가 모두 있으면 덮어쓰지 않습니다. 실리 브라우저도 새로고침하세요. 초기 Sili 앱은 앱 식별자가 달라 별도 설치이며, 초기 앱의 기기 데이터는 자동 이전되지 않습니다. 이미 Silly 이름을 쓰는 사용자는 이 이전을 반복하지 않습니다.

## 오프라인 보관 — Android

1. 온라인에서 원하는 대화를 열고 **상단 도구 → 현재 대화 오프라인 보관**을 선택합니다.
2. 폰 화면 잠금을 인증하고 보관 완료 안내를 기다립니다.
3. 서버가 꺼져도 앱의 **도구 → 오프라인 책장 열기**에서 인증 후 저장한 대화를 읽습니다. 앱을 다시 켜서 서버 연결에 실패해도 상단 도구는 사용할 수 있습니다.

화면 잠금 PIN·패턴·비밀번호가 필요합니다. Android Keystore 키로 암호화하며 본문·제목·번역·사진·책갈피를 사본으로 보관합니다. 개별 삭제·전체 비우기·잠그기를 지원합니다. 앱을 벗어나거나 인증 시간이 만료되면 다시 잠급니다.

한 대화 최대 5,000개 메시지/표시 본문 16MB, 보관함 최대 20개 대화/총 128MB입니다. 같은 대화를 다시 보관하면 최신 사본으로 바뀝니다. 앱 제거·앱 데이터 삭제·키 무효화로 사본을 잃을 수 있으므로 실리 원본을 유지하세요.

## 오프라인 보관 — iPhone·iPad·PC 웹

1. **HTTPS 책방 주소**에 접속합니다. 홈 화면 웹앱을 쓸 경우 설치한 **아이콘으로 열어** 보관하세요. Safari와 홈 화면 웹앱의 저장 공간이 공유된다고 가정하지 않습니다.
2. 대화를 열고 **도구 → 현재 대화 보관 / 갱신**을 누릅니다. 최초에는 오프라인 화면·글꼴 준비 후 12자 이상의 **보관함 전용 비밀번호**를 설정합니다. 서버 책방 비밀번호와 별개이며 서버에 전송하지 않습니다.
3. **보관 완료 안내**를 확인합니다.
4. 서버가 꺼져도 **같은 책방 아이콘/주소**로 다시 엽니다. 서버 연결이 실패하면 자동으로 오프라인 보관함이 나타납니다. 연결 확인에 최대 약 4.5초가 걸릴 수 있습니다. 다른 사이트나 파일 앱으로 이동할 필요가 없습니다.
5. 보관함 비밀번호로 잠금을 풀고 저장한 대화를 선택합니다. 이미 켜 둔 웹앱에서는 **이 기기의 오프라인 보관함**을 열면 됩니다.

- 저장 당시의 본문·번역·사진·책갈피, 오프라인 읽기 위치, 글꼴·간격·여백·집중 읽기를 지원합니다. 보관함은 AES-GCM으로 암호화하며 화면을 닫거나 일정 시간 배경에 두면 잠깁니다.
- **개별 삭제 / 보관함 초기화 / 암호화 백업 받기 / 백업 파일 복원**을 지원합니다. 복원 시 백업 당시 비밀번호가 필요하고 현재 보관함을 교체합니다.
- 한 대화 5,000개 메시지/표시 본문 16MB, 보관함 암호문 합계 100MB, 복원 파일 110MB 제한이 있습니다. 실제 저장 가능량은 브라우저에도 영향을 받습니다.
- 보관함은 **기기·브라우저·접속 주소별**입니다. HTTP에서 HTTPS로 주소를 바꾸면 별도 저장 공간입니다. Android 네이티브 보관함과 저장 형식도 다릅니다.
- 보관함 비밀번호는 복구할 수 없습니다. 잊으면 초기화 후 서버에서 다시 보관해야 합니다. 사이트 데이터 삭제나 브라우저의 공간 정리로 사본이 지워질 수 있으므로 중요한 사본은 암호화 백업하세요.

**모든 오프라인 보관본은 독립된 사본입니다.** 서버의 대화 삭제·비밀번호 변경이 기기에 저장된 사본을 원격 삭제하지 않습니다. 최신 내용을 받으려면 서버에 연결한 뒤 다시 보관하세요. 오프라인 읽기 위치는 온라인 위치와 자동 병합하지 않습니다.

## 도구와 화면 이동

- **홈화면**: 캐릭터 책장으로 이동합니다. 대화별 읽던 위치는 유지됩니다.
- **화면 새로고침**: 현재 홈/대화 화면을 유지하며 웹 화면 전체를 다시 불러옵니다.
- **대화 갱신**: 현재 캐릭터·대화·프사를 다시 읽습니다. 목록은 약 30초, 열린 대화는 약 5초마다 자동 확인하며 화면이 숨겨져 있으면 멈춥니다.
- **도구 → 화면과 글꼴 → 대화 속 캐릭터 프사 표시**: 대화 옆 사진을 켜거나 끕니다. 오프라인은 **읽기 도구**에서 설정합니다.
- **도구 → 홈화면 책장**: 보기 방식, 최근 대화 표시 개수를 설정합니다. 글꼴·테마·정렬 등 화면 설정은 기기별입니다.
- **비밀번호 변경**: 현재 비밀번호로 확인하며 변경 후 모든 책방 세션이 만료됩니다. 실리 자체 비밀번호와 로컬 보관함 비밀번호는 바꾸지 않습니다.
- **복구 코드**: 발급 직후 한 번 표시됩니다. 재발급하면 이전 코드는 폐기됩니다. 책방 비밀번호를 잊으면 로그인 화면에서 복구 코드로 재설정합니다. 코드도 없으면 서버 소유자가 `node setup.cjs`로 재설정합니다.

## 채팅 표시와 제한

저장된 `extra.display_text`를 우선하고 알려진 저장 번역 필드와 본문을 사용합니다. 추가 번역·원문에도 지원되는 표시 정규식과 생각 태그 제거를 적용합니다. 빈 표시문을 원문으로 바꾸지 않습니다.

전역 → 사용 허용된 프리셋 → 사용 허용된 캐릭터의 표시용 정규식을 적용합니다. 잘못된 정규식·지원하지 않는 매크로·시간 초과 시 오류를 표시하며 숨기지 않은 원문으로 대체하지 않습니다. 별도 reasoning 필드는 보내지 않습니다. 임의 형식의 생각 내용은 올바른 표시 정규식이 필요합니다.

정적 Markdown/HTML/div/style/표/details를 표시하지만 스크립트·외부 이미지·외부 CSS·외부 링크 이동은 차단합니다. **실리 테마와 모든 확장의 전처리·매크로·JavaScript를 완전히 복제하는 기능은 아닙니다.** 사진은 현재 계정의 PNG 카드 또는 책방 전용 사진을 사용합니다. 오프라인 사진은 크기 제한이 있어 큰 원본은 제외될 수 있습니다.

현재 남아 있는 캐릭터 카드·그룹 설정을 기준으로 목록을 만듭니다. 삭제된 캐릭터의 잔여 채팅 폴더는 표시하지 않습니다. 실리가 아직 파일에 저장하지 않은 내용은 보이지 않습니다.

대화당 32MiB·10만 메시지, 목록 2만 대화, JSONL 한 줄 약 1MiB 문자 수 제한이 있습니다. 긴 대화는 페이지로 나눠 불러옵니다. 정규식은 별도 worker에서 페이지당 2초 제한으로 실행합니다. 메시지 중간 삭제나 종료 직전에는 읽기 위치가 달라지거나 마지막 위치가 저장되지 않을 수 있습니다.

## 개인정보와 원본 보호

- AI 생성·번역 모델을 호출하지 않으며 AI API 키를 요구하지 않습니다. 추가 모델 사용료가 발생하지 않습니다.
- 제작자 채팅 수집 서버·분석 SDK·광고 SDK가 없습니다. 설치만으로 배포자에게 사용자의 채팅을 읽을 권한이 생기지 않습니다.
- 실리 채팅·캐릭터·설정을 읽으며 책방 기능은 원본 JSONL·캐릭터 카드·프롬프트·API 키를 수정하지 않습니다. 책방 사진·별명·책갈피·읽기 위치·인증 정보는 계정별 `.silly-bookshop`에 별도 저장됩니다. 최초 설치의 서버 플러그인 활성화와 초기 Sili 이전 스크립트는 위에서 설명한 별도 작업입니다.
- 서버 관리자·같은 계정/파일 접근 권한 보유자·악성 실리 확장·기기 침해까지 격리하는 구조는 아닙니다. 스크린샷과 최근 앱 화면에 내용이 보일 수 있습니다.
- 테스트 통과와 정식 버전 표시는 무취약성 보증이 아닙니다. [SECURITY.md](SECURITY.md)에 보호 경계와 한계를 공개합니다.

## 문제를 만났을 때

**도구 → 버전과 연결**의 결과와 오류 문구를 확인하세요. 403이면 실리 메인 화면에서 먼저 로그인하고, 업데이트 직후라면 서버 재시작과 화면 새로고침을 해 주세요. 본문 로딩 실패에는 ‘다시 불러오기’를 사용할 수 있습니다.

일반 오류는 [Issues](https://github.com/foreverharibo-boop/Silly-Bookshop/issues)에 기기/OS·앱/서버 버전·재현 순서를 알려 주세요. **채팅 원문·비밀번호·복구 코드·쿠키·API 키는 올리지 마세요.** 보안 제보는 [SECURITY.md](SECURITY.md)를 따릅니다.

## 검증 상태와 소스 이용

베타에서의 일반 기능 테스트는 배포자가 완료했다고 보고했습니다. 1.0.0의 자동 검사·빌드 결과와 아직 별도 확인이 필요한 **실제 iPhone/iPad HTTPS 오프라인 실행**은 [TESTING.md](TESTING.md)에 구분해 기록합니다. 사용자 기기에서 수행한 테스트와 개발 환경의 Chromium 검사는 서로 다른 범위입니다.

현재 자체 소스의 라이선스는 `UNLICENSED`입니다. 공개 저장소라는 이유만으로 자유로운 수정·재배포 권한을 부여하지 않습니다. 포함한 오픈소스 라이브러리·글꼴은 각각 동봉된 라이선스를 따릅니다.

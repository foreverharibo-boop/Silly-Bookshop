# 실리 책방 · Silly Bookshop

**0.6.0-test.1 · 공개 배포 전 테스트 버전**

실리의 채팅을 읽는 개인용 웹 화면과 안드로이드 앱입니다. 각 사용자는 **자기 실리 서버**에 이 서버 플러그인을 설치하고, 앱에 자기 서버 주소를 입력합니다. 중앙 채팅 서버나 제작자 계정은 필요하지 않습니다.

실리 캐릭터 프사, 캐릭터 바로 아래로 펼쳐지는 대화 목록, 말풍선, 저장된 번역·표시 정규식·HTML/div/CSS 화면, 화이트·크림·로즈·세이지·밤서재·잉크 테마, 글꼴·굵게 표시·글자 크기와 기기 사이 읽던 위치 복원을 지원합니다.

## 0.6.0 도구와 비밀번호

앱 맨 위의 **도구** 또는 웹 책방 헤더의 **도구**를 누릅니다.

- **화면과 글꼴**: 6개 테마, 기기 기본·나눔고딕·나눔명조·고운바탕, 15/16/18/20px, 굵은 글씨. 이 기기의 브라우저/앱에만 저장되며 실리 settings.json과 채팅 원본을 수정하지 않습니다. 글꼴은 서버에 포함되어 외부 글꼴 사이트에 연결하지 않습니다.
- **비밀번호 변경**: 로그인 후 현재 비밀번호, 새 비밀번호(12~256자), 확인을 입력합니다. 완료되면 모든 기기가 잠기며 새 비밀번호로 다시 로그인합니다. 기존 대화·읽던 위치는 유지됩니다. 실리 자체 로그인 비밀번호는 바꾸지 않습니다.
- **복구 코드**: 도구에서 현재 비밀번호로 발급합니다. 새 설치의 터먹스 setup.cjs도 코드를 발급합니다. 기존 0.5.0 사용자는 도구에서 미리 발급해 따로 보관하세요. 코드는 발급 직후 한 번만 표시되며 서버에는 해시만 저장됩니다. 재발급하면 이전 코드는 폐기됩니다.
- **비밀번호를 잊었을 때**: 로그인 화면의 ‘비밀번호를 잊었어요’ → 복구 코드와 새 비밀번호 입력. 재설정 후 표시되는 새 복구 코드를 보관하세요. 기존 비밀번호를 보여주거나 이메일로 보내는 기능은 아닙니다. 실리 자체 인증을 설정했다면 먼저 그 인증을 통과해야 합니다.
- **코드도 없을 때**: 서버 주인이 터먹스에서 실리를 멈추고 `node setup.cjs`로 재설정한 뒤 재시작합니다. 별도 실리 계정은 해당 사용자 데이터 경로를 지정하세요.

| 버튼 | 동작 |
| --- | --- |
| 앱 맨 위 **화면 새로고침** | 웹 화면 전체를 다시 로드. 서버 업데이트 후 화면 파일을 다시 받을 때 사용 |
| 채팅방 **대화 갱신** | 읽던 위치를 저장하고 현재 캐릭터 목록·프사·열린 대화를 다시 읽음 |

0.5.0에서 업데이트: 실리 서버를 Ctrl+C로 멈춘 뒤 아래를 실행하고, 0.6.0 APK를 기존 0.5.0 앱 위에 설치하세요. 앱 삭제나 비밀번호 초기화는 필요 없습니다.

```sh
cd ~/SillyTavern/plugins/silly-bookshop &&
git pull --ff-only &&
cd ~/SillyTavern &&
bash start.sh
```

## 설치 구조

이 저장소를 통째로 `SillyTavern/plugins/silly-bookshop`에 clone하면 최상위 `package.json`의 `main: server/index.cjs`로 로드됩니다. **일반 확장 설치 메뉴에 넣지 않습니다.** 실행용 외부 npm 의존성이 없어 `npm install`도 필요 없습니다.

Android 8 이상 / Node.js 18 이상. 실리가 실행 중이어야 읽을 수 있습니다. 실리 계정을 쓰는 경우 각 계정의 채팅만 읽습니다.

## 터먹스에 최초 설치

먼저 실리 서버를 `Ctrl+C`로 중지합니다. 기존 실리 경로가 `~/SillyTavern`인 경우:

```sh
cd ~/SillyTavern
read -r -p "책방 깃허브 저장소 주소를 붙여넣으세요: " SILLY_REPO_URL
git clone -- "$SILLY_REPO_URL" plugins/silly-bookshop
cd plugins/silly-bookshop
node scripts/enable-plugin.cjs
node setup.cjs
```

아직 저장소를 만들지 않았다면 위 clone 단계는 기다려 주세요. 먼저 이 공개용 ZIP을 압축 해제해서 **그 안의 파일/폴더를 저장소 최상위에 업로드**합니다. 최상위에 `package.json`, `setup.cjs`, `server`, `android`가 보여야 합니다. ZIP 파일 자체를 올리는 것으로는 clone 설치가 되지 않습니다. 숨김 파일 `.gitignore`, `.gitattributes`도 포함하세요.

`enable-plugin.cjs`는 config.yaml을 백업하고 `enableServerPlugins`만 true로 바꿉니다. 기존의 다른 서버 플러그인도 함께 활성화될 수 있습니다. 이미 true이면 파일을 바꾸지 않습니다.

비밀번호는 **12자 이상**으로 두 번 입력합니다. 글자나 별표가 화면에 안 나오는 게 정상입니다. 기본 계정이 아니라면 사용자 데이터 폴더를 직접 지정하세요:

```sh
node setup.cjs "$HOME/SillyTavern/data/사용자핸들"
```

사용자 지정 실리 경로라면 `enable-plugin.cjs` 뒤에 config.yaml 전체 경로를 넣을 수 있습니다. 비밀번호를 잊었을 때도 setup.cjs로 재설정하며 이전 로그인은 무효화됩니다.

실리 다시 시작:

```sh
cd ~/SillyTavern
bash start.sh
```

콘솔에 `[실리 책방 0.6.0-test.1] /api/plugins/silly-bookshop/`가 표시됩니다.

## 채팅방을 열지 않고 바로 읽기

**0.4.0부터 화면 연동이 필요 없습니다.** 실리 서버만 실행 중이면 책방에서 캐릭터와 대화를 골라 바로 읽습니다. 실리 브라우저에서 채팅방을 열거나 과거 메시지를 스크롤할 필요가 없습니다. 추가 AI/번역 API 호출도 없습니다.

- 저장된 `extra.display_text`를 우선 표시합니다. 그 값이 없으면 알려진 저장 번역 필드를 사용하고, 번역이 없으면 저장된 본문을 표시합니다. 빈 표시문은 원문으로 대체하지 않습니다.
- 추가 저장 번역은 메시지 아래에서 펼쳐 읽을 수 있습니다. 원문/다른 번역 모두 같은 표시 정규식과 생각 태그 제거를 거칩니다.
- 현재 계정의 전역 → 사용 허용된 현재 프리셋 → 사용 허용된 캐릭터 정규식 순서로 처리합니다. 화면용(`markdownOnly`) 정규식의 활성 상태, 사용자/AI/내레이터 위치, 최소·최대 깊이, 캡처 그룹·trimStrings를 반영합니다. 프롬프트 전용 정규식과 이미 저장 때 처리된 입력용 규칙을 재적용하지 않습니다.
- `{{char}}`, `{{user}}`, `{{chatid}}`, `{{getvar::이름}}`, `{{getglobalvar::이름}}`, `{{newline}}`, `{{trim}}`을 지원합니다. 계산·스크립트·랜덤 등 실리의 모든 매크로와 다른 확장의 전처리기는 지원하지 않습니다. 지원하지 않는 정규식 매크로나 잘못된 정규식은 해당 메시지에 오류를 표시하며 미처리 원문으로 대체하지 않습니다.
- 그룹은 저장된 메시지의 `original_avatar`를 기준으로 허용된 캐릭터 정규식을 선택합니다. 실리에서 현재 선택한 그룹 멤버에 따른 임시 표시와 다를 수 있습니다.
- 별도 reasoning 필드는 읽기 응답에 넣지 않습니다. 본문에 섞인 think/thinking/reasoning/analysis 태그와 설정된 reasoning 구분자도 제거합니다. 모든 임의 형식의 생각 내용을 자동 식별하는 것은 아니므로 다른 형식은 실리의 표시용 정규식이 필요합니다.
- Markdown, HTML/div/style/표/details를 표시합니다. HTML 코드 블록도 정적 카드로 표시합니다. 실리 테마·외부 폰트·특수 확장 전용 CSS/JavaScript까지 복제하지 않습니다.
- HTML 스크립트·iframe·외부 이미지·외부 CSS·네트워크 요청은 실행하지 않습니다. 이전 화면 복사본은 본문 읽기에 사용하지 않습니다.

생성/번역/설정이 실리 파일에 저장된 뒤 반영됩니다. 열어 둔 대화는 약 5초 간격으로 자동 확인하며 새로고침하면 즉시 다시 읽습니다. 오래된 대화는 책방의 이전/다음 대화 버튼으로 읽으면 됩니다.

## 로그인 순서

실리에 사용자 계정 로그인/기본 인증을 설정했다면 먼저 그 인증을 통과합니다. 이미 로그인된 세션이라면 화면이 생략될 수 있습니다. 실리 자체 인증을 쓰지 않으면 책방 비밀번호만 입력합니다. IP 허용 목록·테일스케일 제한 등 기존 실리 접속 규칙은 그대로 적용합니다.

## 불러오기에 실패할 때

- 0.4.1은 본문 표시 라이브러리를 `rich.js` 하나에 포함합니다. 설치 시 별도 빌드/npm 설치는 필요 없습니다.
- 본문 표시 파일이 실패해도 비밀번호 확인·로그인·캐릭터 목록·잠금은 동작합니다. 대화를 열 때 파일을 다시 요청하고, 계속 실패하면 본문에 ‘다시 불러오기’를 표시합니다. 서버 업데이트/재시작 뒤 이 버튼으로 복구할 수 있습니다.


- 무응답은 최대 20초 뒤 오류와 ‘다시 불러오기’ 버튼으로 바뀝니다. 계속 로딩 문구만 유지하지 않습니다.
- 사진은 화면에 가까운 것부터 동시에 2개까지만 읽으며 일시적 429 오류를 재시도합니다. 사진 실패를 영구 캐시하지 않습니다. 채팅방의 ‘대화 갱신’으로 다시 요청할 수 있습니다.
- HTML 표시 파일이 누락됐거나 서버 버전이 맞지 않으면 안내합니다. 책장 아래에 서버/화면 버전이 표시됩니다.
- 현재 계정의 PNG 캐릭터 카드가 있는 캐릭터만 표시합니다. 사진을 읽지 못하면 이름 첫 글자로 대신 표시하며 새로고침으로 재요청합니다.

## APK 연결

공개용 소스 ZIP에 APK나 서명 키를 섞지 않습니다. 테스트 APK 또는 이후 GitHub Releases의 APK를 폰에서 열어 설치하세요.

- 실리 터먹스가 있는 **같은 폰**: `http://127.0.0.1:8000`
- 다른 안드로이드 기기: 테일스케일을 켜고 `http://100.x.y.z:8000` 또는 해당 `.ts.net` 주소
- 별도 HTTPS 서버: 본인이 관리하는 `https://서버주소`

포트가 다르면 8000을 실제 포트로 바꿉니다. 실리 기본 주소만 넣으면 책방 경로는 자동으로 붙습니다. 하위 경로 프록시는 지원하지 않습니다.

실리 자체 인증이 있으면 먼저 실리 로그인 후 위쪽 **책방**을 누르고, 책방 비밀번호를 입력합니다. 0.5.0은 앱 식별자를 `app.silly.bookshop`으로 바꿔 새 앱으로 설치됩니다. 새 앱에 서버 주소를 한 번 입력하고 기존 책방 비밀번호로 로그인하세요. 정상 작동 확인 후 예전 앱을 삭제하면 됩니다. 읽던 위치와 비밀번호는 서버 데이터 이전으로 보존됩니다. 기존 HTTP LAN 주소(192.168.x.x 등)는 이 버전에서 차단하므로 localhost/테일스케일/HTTPS 주소로 바꿔 주세요.

0.3.1부터 앱의 스크린샷 차단 설정을 제거했습니다. 일반 캡처가 가능하며 최근 앱 화면에도 내용이 보일 수 있습니다. 서버 주소를 변경하면 앱 안의 이전 쿠키와 웹 저장 데이터를 비웁니다.

## 컴퓨터에서 읽기

테일스케일로 실리를 여는 주소 뒤에 `/api/plugins/silly-bookshop/`를 붙입니다. 예:

```text
http://100.x.y.z:8000/api/plugins/silly-bookshop/
```

403이면 같은 서버의 실리 메인 화면에서 먼저 로그인하고 돌아오세요. 네트워크 제한 안내가 나오면 localhost/테일스케일/HTTPS를 확인합니다. 실리의 기존 IP 허용 목록과 로그인 제한은 그대로 적용됩니다.

## 캐릭터 목록과 새로고침

- 현재 실리에 남아 있는 캐릭터 카드 기준으로 목록을 만듭니다. 삭제된 캐릭터의 채팅 폴더가 남아 있어도 표시하지 않습니다. 저장된 채팅이 없는 현재 캐릭터도 표시합니다.
- 그룹은 현재 그룹 설정에 등록된 대화만 표시합니다. 삭제된 그룹의 남은 파일은 표시하지 않습니다.
- 책방의 **새로고침**은 캐릭터·채팅 추가/삭제와 프사를 다시 읽고, 열어 둔 대화도 다시 불러옵니다. 현재 캐릭터나 대화가 삭제되었다면 본문과 선택을 비웁니다.
- 실리에 저장된 파일 기준이며, 실리 화면의 검색·정렬·즐겨찾기 설정까지 복제하지는 않습니다. 삭제된 원본 파일을 책방이 직접 정리하거나 삭제하지 않습니다.
- 목록은 화면이 보이는 동안 약 30초마다 자동 확인합니다. 수동 새로고침은 이 주기를 기다리지 않습니다. 본문은 저장된 번역과 현재 표시 정규식을 적용합니다.

## 동작과 저장 위치

- 활성 대화는 약 5초, 목록은 약 30초 간격으로 서버 파일을 확인합니다. 화면이 숨겨져 있으면 폴링을 멈춥니다.
- 생성 중 아직 실리가 파일에 저장하지 않은 내용은 표시되지 않습니다.
- 읽던 위치는 스크롤을 멈춘 뒤 약 0.65초 후 저장됩니다. 같은 대화를 다른 기기에서 열면 이어 읽습니다. 동시에 읽으면 마지막 저장이 적용됩니다.
- 글자 크기·테마·목록 접힘·최근 선택 ID는 기기 웹 저장소에 보관합니다. 대화 본문을 오프라인 보관하지 않습니다.
- 서버 추가 파일은 해당 계정의 `data/<handle>/.silly-bookshop/auth.json`, `reading.json`입니다. 이전 `rendered/` 복사본은 남아 있어도 읽기에 사용하지 않습니다. 비밀번호는 salt+scrypt 해시로 저장합니다.
- 원본 JSONL과 `settings.json`, 프롬프트, API 키, 다른 확장 파일은 변경하지 않습니다.
- 추가 AI 호출, 분석/광고 SDK, 제작자 알림, 외부 이미지 자동 요청이 없습니다.

## 기존 설치를 Silly 이름으로 이전하기

0.5.0부터 설치 폴더는 `plugins/silly-bookshop`, 접속 주소는 `/api/plugins/silly-bookshop/`, 계정 데이터는 `.silly-bookshop`, 앱 식별자는 `app.silly.bookshop`입니다. 표시 이름은 계속 **실리 책방**입니다.

1. 공개 ZIP의 **silly-bookshop 폴더 안 내용 전체**를 기존 GitHub 저장소에 업데이트합니다.
2. 실리를 Ctrl+C로 종료합니다. 처음에 이전 이름으로 설치했다면:

```sh
cd ~/SillyTavern/plugins/sili-library &&
git pull --ff-only &&
node scripts/migrate-silly.cjs &&
cd ~/SillyTavern &&
bash start.sh
```

이 명령은 설치 폴더 이름을 `silly-bookshop`으로 바꾸고 `.git`을 보존합니다. 기본 data 폴더 안 각 계정의 기존 책방 데이터도 새 이름으로 옮깁니다. 사용자 지정 데이터 경로는 첫 접속 때 이전합니다. 비밀번호·읽던 위치·채팅 ID는 그대로 유지됩니다. 이전·새 데이터 폴더가 모두 있으면 덮어쓰지 않고 안내합니다.

기존 화면 연동 확장만 `SillyTavern/silly-bookshop-backups/`로 옮겨 확장 목록에서 제거합니다. 다른 확장과 실리 settings.json은 수정하지 않습니다. 실행 중인 옛 확장 코드를 끝내려면 **실리 브라우저를 한 번 새로고침**하세요. 새 설치에는 브라우저 확장이 필요 없습니다.

3. **0.5.0 APK를 새로 설치**하고 서버 기본 주소를 입력합니다. 같은 폰은 `http://127.0.0.1:8000`입니다. 기존 책방 비밀번호로 로그인하면 됩니다. 새 앱에서 읽기가 되는지 확인한 뒤 예전 앱을 삭제하세요.
4. PC 즐겨찾기는 실리 기본 주소 뒤에 `/api/plugins/silly-bookshop/`을 붙인 새 주소로 바꿉니다.

이미 폴더 이름이 바뀐 뒤의 업데이트:

```sh
cd ~/SillyTavern/plugins/silly-bookshop &&
git pull --ff-only &&
node scripts/migrate-silly.cjs &&
cd ~/SillyTavern &&
bash start.sh
```

## 읽기 위치와 테마

- 처음 여는 대화는 항상 **첫 번째 메시지, 맨 위**에서 엽니다. 다른 채팅의 스크롤 위치를 이어받지 않습니다.
- 읽다가 스크롤을 멈추면 대화별 위치를 자동 저장합니다. 다시 열거나 다른 기기에서 같은 대화를 열면 마지막 저장 위치를 복원합니다. 화면 높이가 바뀌는 HTML도 위치를 보정합니다.
- **처음으로 ↑**를 누르면 언제든 첫 메시지로 돌아갈 수 있습니다. 이미 읽던 위치가 있는 대화는 업데이트 후에도 그 위치를 유지합니다.
- 상단 **테마 선택**에서 화이트·크림·로즈·세이지·밤서재·잉크를 고릅니다. 선택한 테마는 해당 브라우저/앱에 저장됩니다. 새 APK는 별도 앱이므로 처음에는 테마를 다시 골라야 합니다.

## 현재 제한

HTML과 CSS의 정적 표시는 지원하지만 스크립트·외부 리소스·외부 링크 이동은 차단합니다. 대화당 32MiB, JSONL 한 줄 약 1MiB 문자 수, 10만 메시지, 목록 2만 대화 제한이 있습니다. 한 번에 최대 30개 메시지와 약 2MiB의 메시지 데이터를 반환하며 큰 페이지는 더 작게 나눕니다. 첫 메시지는 크기에 따라 이 응답 목표를 넘을 수 있습니다. 읽던 위치의 메시지가 중간 삭제되면 위치가 달라질 수 있습니다.

표시 정규식은 별도 worker에서 페이지당 2초·메모리 제한으로 실행합니다. 시간 초과/오류는 안내하며 미처리 원문을 내보내지 않습니다. 설정 파일은 최대 64MiB, 캐릭터 메타데이터는 4MiB까지 읽습니다. HTML 프레임 높이는 최대 200,000px입니다.

30분 동안 사용하지 않거나 로그인 후 24시간이 지나면 재로그인이 필요합니다. 실리 서버를 다시 켜도 재로그인이 필요합니다. 앱 종료/네트워크 단절 직전의 위치는 저장되지 않을 수 있습니다. 오프라인 읽기는 아직 없습니다.

실제 폰·터먹스 실기 테스트는 아직 완료하지 않았습니다. 공개하기 전에 [TESTING.md](TESTING.md)를 확인하세요. 보안 범위는 [SECURITY.md](SECURITY.md), 공개 절차와 앱 빌드는 [PUBLISHING.md](PUBLISHING.md)에 있습니다.

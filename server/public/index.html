홈화면 책장

이어 읽기 제목을 눌러 접고 펼쳐요. 보기 방식과 접힘 상태는 이 기기에 저장돼요.

오프라인 보관

서버가 꺼져도 저장한 대화를 읽어요. 처음 준비할 때 HTTPS 연결과 보관함 전용 비밀번호가 필요해요.

버전과 연결

연결 진단을 누르면 앱·화면·서버 버전과 연결 상태를 확인해요.

비밀번호와 복구

책방 비밀번호를 관리할 수 있어요.

복구 코드만 발급할 때는 현재 비밀번호만 입력해 주세요. 재발급하면 이전 코드는 사용할 수 없어요.

비밀번호 관리는 책방 잠금을 푼 뒤 사용할 수 있어요.

비밀번호 재설정

미리 보관한 복구 코드로 새 비밀번호를 설정해요. 변경하면 모든 기기에서 다시 로그인해야 해요.

복구 코드도 없나요?

서버를 실행한 터먹스에서 실리를 Ctrl+C로 멈춘 뒤 아래 명령으로 새 비밀번호를 설정할 수 있어요.

cd ~/SillyTavern/plugins/silly-bookshop
node setup.cjs
cd ~/SillyTavern
bash start.sh

설치 위치나 실리 사용자 폴더가 다르면 해당 경로를 사용해 주세요. 기존 비밀번호는 복원할 수 없으며, 대화·읽던 위치는 지워지지 않아요.

복구 코드를 보관해 주세요

이 화면을 닫으면 코드를 다시 볼 수 없어요. 비밀번호 관리자처럼 안전한 곳에 따로 보관해 주세요. 이전 코드는 사용할 수 없어요.

이 코드가 있으면 책방 비밀번호를 재설정할 수 있어요. 다른 사람에게 공유하지 마세요.

대사 옆 ☆로 남겨요. 메시지를 삭제하거나 순서를 바꾸면 가리키는 위치가 달라질 수 있어요.

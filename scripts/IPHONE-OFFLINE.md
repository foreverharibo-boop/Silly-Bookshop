# 📖 아이폰에서 서버 없이 저장한 대화 읽기

서버·웹 **정식 1.0.1** 안내입니다. Android APK도 정식 **1.0.1**을 제공합니다. 아이폰 8에서 사용자 사용 성공 보고를 받았습니다. 아래 마지막 확인 단계도 자신의 기기에서 진행해 주세요.

한 번 준비하고 대화를 보관하면, 서버가 꺼졌을 때도 **같은 책방 아이콘**에서 보관함을 열도록 만들어져 있습니다. 다른 사이트에 대화를 올리지 않습니다. 미리 보관하지 않은 대화와 이후 추가된 메시지는 서버가 켜져 있어야 읽을 수 있어요.

## 1. 서버 폰에서 준비하기

아래는 **갤럭시 공기계 + Termux + Tailscale** 기준입니다. 아이폰과 서버 폰의 Tailscale을 켜 주세요. 실리가 실행 중이면 터먹스에서 `Ctrl+C`로 잠시 멈춥니다.

책방 폴더로 이동:

```bash
cd ~/SillyTavern/plugins/silly-bookshop
```

업데이트:

```bash
git pull --ff-only
```

업데이트가 오류로 멈추면 다음으로 넘어가지 마세요. 기존 수정 파일을 지우거나 강제로 초기화하지 말고 오류 내용을 먼저 확인해 주세요.

인증서를 만드는 도구 설치:

```bash
pkg install openssl-tool
```

준비 프로그램 실행:

```bash
node scripts/setup-https.cjs
```

질문 세 개가 나옵니다.

1. **서버 폰의 Tailscale IP**: Tailscale에서 실리가 돌아가는 갤럭시 기기를 눌러 `100.`으로 시작하는 주소를 넣어요. 아이폰 주소가 아닙니다.
2. **기존 실리 포트**: 원래 주소에서 `:8001`이었다면 `8001`. 그대로라면 Enter.
3. **새 HTTPS 포트**: 기본값 `8443`을 쓰려면 Enter.

완료하면 **인증서 이름, SHA-256, 새 주소**가 나옵니다. 아이폰 안내와 비교할 수 있게 이 화면을 남겨 두세요.

실리를 다시 시작:

```bash
cd ~/SillyTavern
```

```bash
bash start.sh
```

이후에도 평소처럼 실리를 시작하면 HTTPS 입구가 함께 열립니다. Tailscale이 먼저 켜져 있어야 해요. `HTTPS` 오류가 나오면 원래 주소의 **도구 → 아이폰 오프라인 준비**에서 원인을 확인할 수 있어요.

## 2. 아이폰에서 한 번 설정하기

1. Safari에서 **지금까지 쓰던 책방 주소**를 열고 로그인합니다.
2. **도구 → 아이폰 오프라인 준비**를 누릅니다.
3. 표시된 인증서 이름·SHA-256이 방금 내 서버 터먹스에 나온 것과 같은지 확인합니다. **아이폰용 인증서 받기 → 허용**을 누릅니다.
4. 아이폰 **설정 → 일반 → VPN 및 기기 관리 → Silly Bookshop … → 설치**. ‘프로파일이 다운로드됨’이 보이면 그 항목으로 들어가도 됩니다.
5. 설치 완료 화면 오른쪽 위 **완료**를 누릅니다. 설치 화면에는 전체 신뢰 스위치가 없습니다. **설정 → 일반 → 정보 → 맨 아래 인증서 신뢰 설정**에서 방금 설치한 `Silly Bookshop …`의 **전체 신뢰**를 켭니다.
6. 책방의 준비 안내로 돌아와 **새 주소 링크**를 Safari에서 엽니다.

인증서는 **본인의 서버에서 만든 것만** 설치해 주세요. 이것은 아이폰의 인증서 신뢰 설정에 영향을 주는 작업입니다. 제공되는 파일에는 루트 인증서 하나만 있고 VPN·기기 관리·원격 제어 설정은 없습니다. 서버마다 서로 다른 인증서를 만들며, 다른 인증서를 발급하는 서명용 개인키 파일은 생성 직후 제거합니다. 서버 연결용 개인키는 서버 폰 안에만 남습니다.

Apple은 다운로드한 인증서에 대해 프로파일 설치와 전체 신뢰 설정을 각각 요구합니다: [Apple 안내](https://support.apple.com/ko-kr/102390).

**‘연결이 비공개로 설정되어 있지 않음’ 같은 경고를 무시하고 진행하지 마세요.** 인증서 이름, IP 주소, 위 4·5단계, 기기의 날짜와 인증서 만료일을 확인해 주세요.

## 3. 홈 화면에 추가하고 대화 보관하기

1. 새 주소에서 실리 계정 로그인이 나오면 **실리 계정**으로 로그인한 뒤, **책방 비밀번호**를 입력합니다. 이전 주소의 로그인 정보가 그대로 넘어오지 않을 수 있어요.
2. Safari **공유 → 홈 화면에 추가**. ‘웹 앱으로 열기’가 있으면 켭니다.
3. **홈 화면의 새 실리 책방 아이콘**으로 들어갑니다. HTTP로 만든 옛 아이콘과 구분해 주세요.
4. 원하는 대화를 열고 **도구 → 현재 대화 보관 / 갱신**을 누릅니다.
5. 처음에는 12자 이상의 **보관함 전용 비밀번호**를 정합니다. 이 비밀번호는 기기의 보관본을 여는 용도이며 서버로 보내지 않아요.
6. **‘대화와 오프라인 화면을 모두 보관했어요’**가 나올 때까지 기다립니다.

Safari 탭과 홈 화면 웹앱의 저장 공간은 다를 수 있습니다. **홈 화면 아이콘으로 실행한 안에서 저장해야 합니다.** 준비만 하고 대화를 저장하지 않았다면 오프라인에서 읽을 대화가 없어요.

## 4. 꼭 한 번 확인하기

1. 보관 완료 후 서버의 실리를 끕니다.
2. 아이폰의 책방을 완전히 닫았다가 **같은 홈 화면 아이콘**으로 다시 엽니다.
3. 서버 연결 확인 후 오프라인 보관함이 나타납니다. 최대 약 4.5초가 걸릴 수 있어요.
4. 보관함 비밀번호를 넣고 저장한 대화를 엽니다.

처음 준비할 때 자신의 기기에서 위 순서로 한 번 확인해 주세요. 처음 대화 보관이나 새로운 내용을 받는 동안에는 서버가 켜져 있어야 합니다.

## 자주 궁금한 것

- **원래 갤럭시 APK는요?** 기존 HTTP 주소와 APK 1.0.1을 계속 쓸 수 있어요. 실리의 설정 파일·비밀번호·채팅 원본은 이 준비 프로그램이 바꾸지 않습니다.
- **아이폰에 예전에 저장한 대화는요?** HTTP와 HTTPS 주소는 서로 다른 저장 공간입니다. 새 아이콘 안에서 다시 보관해 주세요. 이미 쓸 수 있는 웹 보관함이 있다면 암호화 백업을 받아 새 주소에서 복원할 수도 있어요.
- **저장한 대화는 영원히 남나요?** 브라우저 데이터 삭제, 아이콘 삭제, 저장 공간 정리 등으로 지워질 수 있습니다. 중요한 대화는 **암호화 백업 받기**로 별도 보관해 주세요. 비밀번호를 잊으면 복구할 수 없어요.
- **인증서가 만료되면요?** 1년짜리입니다. 같은 준비 명령을 다시 실행하고 실리를 재시작한 뒤, 아이폰에서 새 인증서를 설치·신뢰해 주세요. 주소가 같다면 보관함을 이전할 필요가 없습니다. 구 인증서 프로파일은 새 연결 확인 후 제거해 주세요. 서버 IP를 바꾸면 주소와 저장 공간도 바뀌므로 먼저 백업하세요.
- **다른 사람들도 이 인증서를 쓰나요?** 아닙니다. 각자 자기 서버에서 준비 명령을 실행하고 자기 아이폰에 자기 인증서를 설치합니다. 인증서나 개인키를 배포 파일에 넣지 마세요.
- **PC 서버는요?** Node와 OpenSSL이 설치된 컴퓨터에서도 동일한 준비 프로그램을 쓸 수 있지만, 이 안내의 명령·기기 설정은 Termux와 iPhone 기준입니다. Windows/iPad 실기 설정은 별도 확인이 필요합니다. 이미 신뢰되는 HTTPS 주소가 있으면 인증서를 추가할 필요 없이 3단계부터 진행합니다.

HTTPS 입구를 끄고 싶으면 책방 폴더에서 다음 명령 후 실리를 다시 시작하세요. 개인키나 보관본을 삭제하지 않습니다.

```bash
node scripts/setup-https.cjs --disable
```

인증서 프로파일 제거는 아이폰 **설정 → 일반 → VPN 및 기기 관리**에서 해당 `Silly Bookshop …` 프로파일을 선택해 진행합니다.
